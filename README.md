# Aventure Éducative

Application éducative pour les enfants de 6 à 12 ans, sur téléphone et tablette.

L'enfant choisit un monde (Maths, Lecture, Mémoire, Science…), joue à de courtes activités, gagne des étoiles et progresse à son rythme.

- Aucune publicité, aucun achat intégré.
- Aucune donnée de l'enfant envoyée sur Internet : tout reste dans l'appareil.
- Fonctionne sans connexion une fois installée.

Projet en cours de construction (Phase 0 : les fondations).
